# RankGeo Skills

AI agent skills for the RankGeo GEO platform.

## Available skills

- **[rankgeo-cli](./skills/rankgeo-cli/SKILL.md)** — Use the RankGeo CLI to run GEO audits, manage suggestions, trigger ingestion, and check scores from the terminal.

## Install

```bash
npx skills@latest add RankGeo-ai/skills
```

Then select the skills you want.
